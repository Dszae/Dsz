# Creative Portfolio Showcase

A client-side visual portfolio and motion design showcase built with semantic HTML5, CSS3, and GSAP animation triggers.

## Features

- **Typography & Motion:** Interactive typewriter role rotation and GSAP scroll triggers.
- **Modal Previews:** Lightweight client-side media viewer with modal dialog semantics.
- **Responsive Architecture:** Flexbox and grid layouts optimized for desktop and mobile viewports.

## Project Structure

- index.html — Portfolio landing page and section markup.
- style.css — Custom design system, color palette, and responsive breakpoints.
- script.js — Navigation listeners, typewriter loop, and ScrollTrigger integration.
